# Lesson authoring design

Selected: **A — Pracownia**, confirmed by the project owner on 2026-10-14.

The lesson editor uses an exercise outline on the left, with Markdown writing and
student preview side by side on wide screens. Starter code sits below the selected
exercise. Narrow screens stack the writing and preview areas.

The layout uses the real lesson-authoring workflow, including publication,
permissions, confirmation prompts, and unsaved-change protection.

The three original design alternatives are preserved on local branch
`prototype/lesson-authoring-20261014-081823`, commit
`a9466afdbf1a9f0ddce05a6d62e4d382ad199aec`. That branch includes the development-only
`?variant=A`, `?variant=B`, and `?variant=C` comparison on lesson-editor routes.
There was no implementation issue associated with this design exploration.
